THE ONE TOPIC

Priority queue, using an array.

An ordinary queue serves the first arrival. A priority queue serves the most important packet first. Here, smaller priority numbers are more important.

  1. Enqueue: shift lower-priority packets right and insert the new packet.
  2. Peek: the packet at index 0 is next.
  3. Dequeue: remove index 0 and shift the remaining packets left.

The strict > comparison preserves FIFO order for equal priorities. Codec2 and M17 share P3.

Enqueue O(n)Dequeue O(n)Peek O(1)

The array holds up to 8 packets. Storage is O(capacity). No linked lists, graphs, or trees are needed.

USE CASE / KJS-SRS-01

Why this fits SomaiyaSat

A small satellite shares limited communication time between spacecraft health data, images, and voice. This scheduler puts critical telemetry ahead of less urgent payloads.

P1TT&C / housekeepingFirst
P2SSTV imagesThen
P3Codec2 & M17Last

This is a data structures demonstration, not a trained AI. Strict priority can starve voice packets if higher-priority traffic keeps arriving.

The algorithm behind the screen

int i = count - 1;
while (i >= 0 && queue[i].priority > packet.priority) {
    queue[i + 1] = queue[i];
    i--;
}
queue[i + 1] = packet;
count++;
